# Brand

|                              | Light     | Dark      |
| ---------------------------- | --------- | --------- |
| Terracotta ("cotto"), accent | `#a84b25` | `#e8875e` |
| Ink, text                    | `#2a2420` | `#f2ede6` |
| Paper, background            | `#fefcf9` | `#1b1816` |

- `logo.svg`: the mark in terracotta, for light backgrounds. `logo-dark.svg`: for dark backgrounds.
- `favicon.svg`: switches colour with the system theme.
- The mark is a table seen from above: a header bar over three columns, which also reads as a T. It is drawn on a 32 by 32 grid and stays legible at 16 pixels.
- Wordmark and docs headings: Fraunces (SIL Open Font License), weight 600, soft. The table itself ships no web font and inherits the app's font.
- White text on terracotta: 5.68:1. Terracotta text on paper: 5.55:1. Both meet WCAG AA.
