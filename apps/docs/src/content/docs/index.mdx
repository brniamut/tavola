Try it: search, sort with Shift-click for a second column, open a column menu (the dots in a header) to filter or pin, drag a header by its grip, resize from its edge, select rows. Reload the page and your layout is still there.

<CardGrid>
  <Card title="Typed columns" icon="seti:typescript">
    `col.number('name')` does not compile when `name` is a string. The column kind decides the
    filter, the sorting and the formatting.
  </Card>
  <Card title="One query for your server" icon="rocket">
    Pass a `fetcher` and get `{ sort, filters, search, page }`. Debouncing, cancellation, page
    resets and cursor paging are handled.
  </Card>
  <Card title="Styles you can override" icon="pencil">
    Plain CSS in a cascade layer, themed with CSS variables. Your classes and Tailwind win without
    `!important`.
  </Card>
  <Card title="No paid tier" icon="approve-check">
    Pinning, multi-sort, filters, reordering and selection are all MIT licensed, on TanStack Table
    v9.
  </Card>
</CardGrid>
